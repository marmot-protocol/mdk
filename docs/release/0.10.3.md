# MDK 0.10.3

MDK 0.10.3 releases the Rust workspace, WN Agent, MarmotKit (iOS, macOS and
Android), and Marmot C from one source commit. See the
[0.10.2 → 0.10.3 client upgrade guide](../integration/0.10.3.md) for adoption steps.

## Highlights

- Prepared chat rows select draft, message, invitation or empty previews and
  expose advisory row actions. Draft changes refresh both live list APIs without
  changing activity order or unread state. Draft previews contain bounded text
  and attachment summaries, with no attachment bytes or filenames.
- Public profile searches tolerate optional relay authentication challenges.
- Android identity-salt publication supports API 26 without hard links or
  `renameat2`, retaining a single canonical salt under concurrent creation.
- Hermes gains a privacy-safe, read-only installation doctor, connector diagnostic
  status and plugin ACK/lifecycle observations. Configuration precedence and
  welcomer behavior remain aligned with the existing adapter path.

## Compatibility

Ship generated Swift/Kotlin, native libraries and C headers from this exact
cohort together. Prepared chat-row records have changed layout; rebuild clients
and update manually constructed records and exhaustive preview handling.
Existing lower-level methods remain supported. Row actions are display hints;
leave still requires authoritative preflight and deletion requires host confirmation.

No database migration is added after 0.10.2; schema remains at migration 86.
For upgrades skipping earlier releases, follow their backup and unsupported-
downgrade requirements in the [previous guide](../integration/0.10.2.md) and
[storage-format contract](../marmot-architecture/storage-format-v2.md).
Preserve the matching Apple privacy resource in every consuming wrapper. Existing
required-reason and SDK-signing questions remain tracked in
[#1874](https://github.com/marmot-protocol/mdk/issues/1874); SDK artifact validation
is separate from consuming-app adoption and App Store acceptance.

## Release artifacts

- `v0.10.3`: MDK source snapshot; workspace crates remain unpublished to crates.io.
- `wn-agent-v0.10.3`: WN Agent, terminal harness binaries, gateway plugins and
  checksum-paired installers. This track retains its existing prerelease status.
- `marmotkit-v0.10.3`: iOS/macOS XCFrameworks, shared Swift source, platform privacy
  resources, Android Kotlin and all four JNI ABIs, manifests and checksums.
- `marmotc-v0.10.3`: C library/header bundle and checksum.

Verify sibling SHA-256 files and source/version manifests; Apple binary ZIPs also
have SwiftPM checksums. Follow the [distribution guide](../../crates/marmot-uniffi/DISTRIBUTION.md).
